用一句话解释什么是量化（quantization）？
G
量化是用更低精度的数值（如 4-bit / 8-bit 整数）来表示模型权重，在几乎不损失效果的前提下大幅压缩体积、降低显存与算力需求，让大模型能在消费级显卡上跑起来。 例如把 16 位浮点权重转成 4 位： 
FP16:  0.4821  1.9375  -0.3125   ...   (16 bit)
Q4_K:  ▒▒▒▒    ▒▒▒▒    ▒▒▒▒     ...   (≈4 bit + 共享缩放)
你当前用的 Q4_K_M 就是这种方案的常见甜点档。

那 RAG 功能怎么用？
G
在左侧「+ 新建对话」旁的知识库区上传 PDF / TXT / Markdown，Open WebUI 会自动切分、向量化并建立索引。之后在对话里 @ 对应知识库，模型就会基于你上传的文档作答，而不是只靠训练记忆——这就是 RAG（检索增强生成）。

1. 安装 Open WebUI（Docker，Windows）

需先安装 Docker Desktop（开启 WSL2 后端）。管理员 PowerShell 执行：

docker run -d -p 3000:8080 ^
  --add-host=host.docker.internal:host-gateway ^
  -v open-webui:/app/backend/data ^
  -e WEBUI_SECRET_KEY=请改成你自己的强密钥 ^
  --name open-webui --restart always ^
  ghcr.io/open-webui/open-webui:main
关键参数 --add-host=host.docker.internal:host-gateway：让容器内才能访问到宿主机（Windows）上的 llama-server。镜像 :main 较大（≈1.6GB）；若只要纯聊天可换 :slim（≈196MB）。

2. 连接 llama-server（后端在 Windows 宿主）

  1. 浏览器打开 http://localhost:3000，首次访问创建管理员账号（设强密码）。
  2. 进入 ⚙️ Admin Settings → Connections → OpenAI，点 ➕ Add Connection。
  3. URL 填 http://host.docker.internal:8080/v1（容器内能解析到宿主机的 llama-server；不要写 localhost）。
  4. API Key 填 not-needed（llama-server 不校验）。
  5. 若连接校验报错（4xx）但聊天正常，属正常现象：在 Model IDs (Filter) 手动填 gemma-4 并保存。
  6. 返回聊天界面，顶部选 gemma-4 开始对话。

3. 安全提示

  1. 创建管理员后，建议在 Admin Settings 中关闭开放注册（Disable Signup）。
  2. llama-server 已绑定 127.0.0.1（仅本机）；如需局域网共享，注意 Docker 端口映射与防火墙。

完整部署文档见 docs/deploy-guide.md；后端启动脚本见 scripts/start-gemma-server.bat。
